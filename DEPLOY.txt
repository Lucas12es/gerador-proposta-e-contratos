# Deploy: GitHub + Cloudflare

Sem build e sem variáveis de ambiente. Esta pasta (public) é a raiz do repositório: o site fica na raiz e o wrangler.jsonc daqui aponta para ela.

Atalho: dê dois cliques em deploy.bat para enviar tudo ao GitHub pelo CMD.

## 1. GitHub (pelo site, sem terminal)
1. Abra https://github.com/Lucas12es/gerador-proposta-e-contratos
2. **Add file > Upload files**.
3. Abra a pasta do projeto no computador, selecione **tudo** (tudo que está dentro desta pasta, inclusive `wrangler.jsonc` e `.assetsignore`) e arraste para a página. Os arquivos que começam com ponto podem estar ocultos no Windows: ative **Exibir > Itens ocultos** no Explorador de Arquivos.
4. Escreva uma mensagem e clique em **Commit changes**.
5. Para atualizar depois: repita o upload com os arquivos alterados (mesmo caminho) e faça o commit.

## 2. Cloudflare Pages (deploy automático a cada commit)
1. Cloudflare > **Workers & Pages > Create > Pages > Connect to Git** e escolha `gerador-proposta-e-contratos`.
2. Framework preset: **None**. Build command: **(vazio)**. Build output directory: **/** (raiz). Se usar Workers, deploy command: `npx wrangler deploy`.
3. **Save and Deploy**. Cada commit novo publica sozinho.

Alternativa pelo Workers (o `wrangler.jsonc` já está pronto): Workers & Pages > Create > Import a repository, build command vazio e deploy command `npx wrangler deploy`.

## 3. Depois de publicar
- Teste `/`, `/proposta/`, `/contrato/` e `/configuracoes/`.
- Proteja a URL com Cloudflare Access (Zero Trust), pois os dados dos clientes ficam no navegador de quem usa.


IA (GROQ)
Cloudflare > seu projeto > Settings > Variables and Secrets > Add:
  GROQ_API_KEY = sua chave do Groq (tipo Secret)
  ACCESS_CODE  = um código seu (opcional, recomendado)
Depois rode o deploy.bat de novo (ou Retry deployment).
